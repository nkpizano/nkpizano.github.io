Installing R

Need help installing R and R studio for Window or MAC? Check out a step-by-step guide in the All about the Basic: R and R Studio post, which I created back in September.

Starting an R project: Where do I start?

An R project is way to create a small file to organize all the files related to a specific project, including assignments, research study, etc. Starting an R project will set a working direct to the folder where the R project is located. In other words, you don't have to worry about setting up a new working directory using code and dont have to rely on the default working directory.

  • Once you open RStudio, select “File” in the menu bar located at the top left of your screen.
  • A drop-down menu will appear
  • DSelect “New Project”
  • A “New Project Wizard” window will appear
  • Select “New Directory - Start a project in a brand new working directory.”
  • Then you will be prompted to select a “Project Type” , which will depend on your project's purpose, but most likely you will choose “New Project.”
  • Another prompt will appear. In the text box under “Directory Name,” provide a name for your project’s working directory - I will explain more about a working directory below! This should be a broad name (e.g., Assignment 1, or Lab 1). Change the file path for the working directory by selecting the “Browse” button. Do you want your new files on your desktop or in your Google Drive? PLEASE, SELECT “OPEN IN A NEW SESSION”. Then select “Create Project.”
  • Verify that you have a new folder/working directory at the specified file path.

Create a new file in your new project.

  • Select “File” in the menu bar located at the top left of your screen.
  • A drop-down menu will appear
  • Select “New File”
  • A drop-down menu will appear. You will likely be starting a new R Markdown document, but there are some options. For this example, I will be selecting R Markdown.
  • A new window will appear titled “New R Markdown”. In the left panel, “Document” is the default. Provide a title in the Title text box for your R Markdown document ( e.g., Assignment 1 - Regression”), which will appear at the top of your document once rendered. Your name should appear in the Author text box. If not, type out your name in the Author text box. Today’s date will automatically generate. By default “HTLM” will be selected as the “Default Output Format”. If you need to submit a printable document, I suggest using “Word” - for the moment, if you want a PDF, look for more information below!
  • Select “File” in the menu bar located at the top left of your screen.
  • A drop-down menu will appear.
  • Select “Save As …”
  • A new window will open with the directory file path. In the “Save As:” text box, type out a file name. I like to use RMarkdown title as the file name. Then select “Save”.
  • Check that Rmarkdown Tab in the second panel of your screen has the file name.
  • Then it's time to start coding and analyzing! Move your data files into your working directory - the file path you provided at the beginning of setting yourself up.

PDF output

To render your Rmarkdown file into a pdf you will need to install LaTex - a document prep system used for communication and publications!.
  • Highly recommend that you install TinyTeX (https://yihui.name/tinytex/)
  • Use the following code: install.packages('tinytex') tinytex::install_tinytex() # install TinyTeX
  • Now you should be able to render the Rmd file into a pdf by clicking the dropdown menu beside the knit button (a ball of yarn and needle icon) and selecting pdf

What is a working directory in R

The working directory is the default location where R will look for files you want to load and where it will put any files you save.
